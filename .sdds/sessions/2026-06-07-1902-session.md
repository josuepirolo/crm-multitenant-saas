## O que foi feito
- Desativado temporariamente o auto-cadastro (`/register`) via feature flag `SELF_REGISTRATION_ENABLED` em `src/lib/constants/feature-flags.ts` — página mantida no código, renderiza tela "indisponível" quando desligada; link "Criar conta" oculto no login.
- Corrigido bug de captcha reportado em produção: `[requestPasswordReset] Supabase error: captcha protection: request disallowed (timeout-or-duplicate) 400`.
- Causa raiz: dupla verificação do mesmo token Turnstile (single-use) — `validateTurnstile()` próprio chamava `siteverify` da Cloudflare e consumia o token; em seguida o Supabase Auth (GoTrue, com captcha ativo no projeto remoto) tentava verificar o mesmo token e falhava como "duplicate".
- Removido `src/lib/security/turnstile.ts` (verificação redundante); Supabase Auth passou a ser o único verificador via `captchaToken` em `signInWithPassword`/`signUp`/`resetPasswordForEmail` (`src/app/(auth)/actions.ts`).
- Adicionados `CAPTCHA_ERROR` e `isCaptchaError()` em `src/lib/security/security-errors.ts` para traduzir o erro bruto do GoTrue em mensagem amigável sem vazar detalhe interno.
- Corrigido vazamento secundário em `signUp`: fallback retornava `authError.message` cru ao cliente — substituído por mensagem genérica.
- Atualizado `.claude/rules/security-checklist.md` (linha 20) removendo referência ao módulo deletado `turnstile.ts`.
- Reescritos os testes de captcha em `src/tests/security/auth-actions.test.ts` (mocks de `security-errors` + 4 testes novos) e corrigidos 2 testes pré-existentes de `signUp` que já estavam quebrados por falta de `nicheId` (obrigatório desde commit `37b3ee4`).
- Validação: `npx tsc --noEmit` limpo; suíte `src/tests/security/` — 191/191 passando.

## Decisões tomadas
- Manter a verificação de captcha **somente** no Supabase Auth (GoTrue) — não é possível desligar o captcha do dashboard remoto via código/MCP, e remover o pré-check próprio é a única correção viável sem risco de quebrar o auth.
- Auto-cadastro desativado por decisão de produto via flag booleana simples (`feature-flags.ts`), não removido do código — reversível trocando a constante para `true`.
