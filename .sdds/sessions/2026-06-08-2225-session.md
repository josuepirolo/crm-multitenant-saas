7. Server Actions sem auth/Zod
8. Middleware sem matcher / open redirect
9. Dependências com CVEs
10. next.config (SSRF via rewrites, images wildcard, SVG perigoso)
11. Dados sensíveis no __NEXT_DATA__
12. CORS com wildcard
13. XSS (dangerouslySetInnerHTML, href malicioso)
14. CSRF em Route Handlers (diferença Server Actions ≥14 vs Route Handlers)
15. Upload sem magic bytes / path traversal
16. SSRF via fetch() com URL do usuário em Server Actions
17. Dados sensíveis em logs (console.log de session, user, process.env)
