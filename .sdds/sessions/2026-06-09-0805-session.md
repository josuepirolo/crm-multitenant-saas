## O que foi feito

1. **Feedback de importação de contatos** — importação de 3.102 linhas retornava "0 criados / 3.102 ignorados / nenhum erro de validação" sem explicar que eram todos duplicados.
   - `ContactImportResult` ganhou `already_exists`, `invalid_count`, `file_duplicates`.
   - `ImportContactsUseCase` classifica cada linha (criado / já existe / inválido / duplicado no arquivo) e popula os novos contadores.
   - `ImportResultSummary` reescrito: 4 cards (Processadas, Criadas, Já existiam, Inválidas) + aviso de duplicatas no arquivo + mensagem dedicada quando 100% já existe.
   - `useContactImportViewModel`: agrega os novos contadores entre lotes e ajusta o toast final.

2. **Múltiplas origens por contato** (ADR-003) — nova tabela `contact_source_assignments` (N:N contato↔`contact_sources`, RLS por workspace), migration `20260609120000_contact_source_assignments.sql` aplicada via Supabase MCP (`apply_migration`), migrando automaticamente os 8.485 `source_id` existentes. `ImportContactsUseCase.resolveSourceIds` separa origens por vírgula na planilha; `SupabaseContactSourceRepository.assignToContact`/`listForContact` novos. `contacts.source_id` mantido como origem primária.

3. **BUG CRÍTICO DE SEGURANÇA — impersonação não isolava tenant em escritas** (discovery `2026-06-09-impersonation-tenant-isolation-bug.md`, ADR-004):
   - Usuário, impersonando o workspace Lekazis, importou contatos que foram parar no workspace pessoal do superadmin (PyTec) — 8.485 registros.
   - Causa: `getCurrentWorkspaceId`/`getWorkspaceContext` (`guards.ts`) e `getUserRole` (`user-role.ts`) resolviam tenant só por `profiles.current_workspace_id`, ignorando o cookie de impersonação.
   - Fix: nova `getValidatedImpersonatedWorkspaceId(userId)` em `impersonation.ts` (valida dono do cookie + `is_superadmin` no banco); usada nos três pontos acima — acesso owner-like ao workspace impersonado (ADR-004).
   - Cleanup de dados: `DELETE FROM contacts WHERE workspace_id = 'b5a71a25-c2d1-4395-9d66-ac059cff1ce0'` (PyTec, workspace de teste) — removidos 8.485 contatos + `contact_source_assignments` associados (CASCADE).
   - Validação: `tsc --noEmit` limpo; `vitest run src/tests/security src/tests/tenant-isolation` → 307/307 passando.
   - **Cobertura de testes adicionada** (R-008 → RESOLVIDO): `src/tests/security/impersonation-validated-workspace.test.ts` (5 testes de `getValidatedImpersonatedWorkspaceId` — sem cookie, cookie de outro usuário, não-superadmin, `is_superadmin` nulo, caso válido) e `src/tests/security/workspace-context-impersonation.test.ts` (11 testes de `getCurrentWorkspaceId`/`getWorkspaceContext`/`getUserRole`, com e sem impersonação, incluindo regressão do fluxo normal owner). `vitest run src/tests/security src/tests/tenant-isolation` → 323/323 passando (era 307, +16 novos); `tsc --noEmit` limpo.
