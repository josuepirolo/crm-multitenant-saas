# /project-init

Bootstrap projeto Next.js usando `specs_default/`.

1. Ler `specs_default/00-bootstrap-new-project.md`
2. Preencher `TECH_STACK.template.md` com versões confirmadas
3. Conduzir perguntas em `auth/decision-supabase-vs-custom-jwt.md`
4. Propor estrutura de pastas e arquivos base (middleware, globals.css, guards)
5. Copiar skills de `specs_default/skills/` para `.claude/` e `.cursor/`
6. Não incluir SDDS

Entregar checklist do que foi criado e pendências D0.
